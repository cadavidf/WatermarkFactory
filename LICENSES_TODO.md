# License / attribution audit — WatermarkFactory

Reviewed 2026-08-31. Two independent passes: codex (full read-only repo
audit) and my own manual check (Package.resolved, Package.swift for both
local packages, bundled fonts/assets, source comments). Gemini's pass
**could not run** — this account needs `GOOGLE_CLOUD_PROJECT` set for
Workspace auth, an environment gap, not a finding. Worth re-running once
that's fixed, but codex + manual agreed on everything below, so I'm not
holding the app hostage to a third independent pass.

## Doable — done

- [x] **Sparkle 2.9.6** (`sparkle-project/Sparkle`) — the only real
  third-party runtime dependency. MIT-style license plus four embedded
  sub-licenses (bsdiff/bspatch, sais-lite, ed25519, SUSignatureVerifier.m —
  all permissive MIT/BSD/zlib-style). Full verbatim text now shown in-app
  via App menu → **Acknowledgements…** (`AcknowledgementsView.swift`).
  Codex's audit flagged my first pass as a summary rather than verbatim
  text — fixed, now the actual license text word-for-word.

## Checked, nothing owed

- **DesignSystemKit**, **AutomalityUI** — both local packages, both zero
  external dependencies, both original code by this repo's owner. No
  attribution obligation; noted as such in the Acknowledgements window so
  it's not ambiguous to a future reader.
- **App icon** (`assets_src/`, `Assets.xcassets`) — generated by
  `scripts/make_icon.py` from geometric shapes and Automality's own color
  tokens. No third-party art.
- **Fonts** — none bundled. AutomalityUI references Space Mono/Inter/
  JetBrains Mono by name as *preferred system fonts* (falls back gracefully
  if not installed), not embedded font files — no redistribution
  obligation.
- **SF Symbols** (`Image(systemName:)`) — ordinary in-app icon usage.
  Confirmed against Apple's current HIG: no attribution required; the
  restrictions that exist (no use as app icon/logo, no trademark-like use)
  don't apply here.
- **Source code scan** — no comments or patterns indicating code adapted
  from Stack Overflow, Apple sample code, gists, or other unattributed
  sources. The one algorithmic item worth naming, `DesignSystemKit`'s 4x4
  Bayer dither matrix, is a standard, publicly-known table — not something
  requiring attribution.

## Not doable / not applicable

- Nothing found in this category. There's exactly one real dependency
  (Sparkle) and it's handled.

## Process note for next time a dependency is added

This list is only as good as the last audit. When a new SPM package (or
anything else third-party) gets added to WatermarkFactory, DesignSystemKit,
or AutomalityUI: add its license to `AcknowledgementsView.swift`'s
`Acknowledgements.entries` verbatim (not summarized — see the fix above for
why), and add a line here. Don't rely on remembering to do this manually
forever; if the dependency surface grows past one or two entries, consider
scripting a `Package.resolved` diff check into the release process instead.
